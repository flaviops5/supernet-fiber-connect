# Support Tech Media Assets

Este diretório contém os assets de mídia usados pelo agente de suporte técnico (Luan) para melhorar a taxa de resolução remota.

## Imagens

- `los-blinking-placeholder.png` - Imagem mostrando luz LOS vermelha piscando no ONU
- `reconnect-fiber-placeholder.png` - Guia visual de como reconectar a fibra
- `onu-front-simple.png` - Vista frontal simplificada do ONU com luzes indicadoras

## Áudios

Os áudios estão em `public/campaign-media/support-tech-audio/`:
- `cloe_solicita_cpf_v1.[mp3,ogg,wav]` - Cloé solicitando CPF
- `luan_los_detectado_v1.[mp3,ogg,wav]` - Luan explicando LOS detectado
- `luan_reconectar_fibra_v1.[mp3,ogg,wav]` - Luan guiando reconexão da fibra

## Uso

Estas mídias são usadas nos cenários:
- **Cenário A (LOS detectado)**: Imagem + áudio explicativo
- **Cenário de Reconexão**: Vídeo/imagem + áudio guiado
- **Diagnóstico visual**: Imagem frontal do ONU

## Linguagem

Todas as mídias usam linguagem simples e humanizada:
- ✅ "Conector verde - parte onde a fibra entra"
- ✅ "Luz vermelha LOS"
- ❌ Evitar termos técnicos como "conector SC/APC", "PON loss of signal"
